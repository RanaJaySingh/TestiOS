# PIP-103 [iOS] History entry (open → save)

Ticket: https://linear.app/telco-paytm/issue/PIP-103/history-entry-open-save

## Delivered

Open History entry → one-time percentage change, create goal, Save and lock. Goal totals update on Save only. Suggested standing split + `customSplit` flag. Pi* visuals retained from PIP-85. Ledger engine stubbed until PIP-98 merges.

| Type / file | Role |
|-------------|------|
| `HistoryEntry.customSplit` | Flag when this-credit % ≠ suggested standing |
| `CreditEntryService` | `suggestedStandingPercentages`, `isCustomSplit`, `addGoalToOpenCredit`, lock sets `customSplit` |
| `LedgerEngine` + `StubLedgerEngine` | PIP-102 protocol + stub extended with PIP-103 Save / create-goal; Sync/Update via `processBalanceUpdate` |
| `LedgerFacade` | PIP-99 Consent / opening balance (coexists) |
| `HistoryService` | `showsCustomSplitBadge` / `showsTypedBadge` |
| `CreditEntryView` + `CreditEntryViewModel` | Create goal sheet; Custom badge from flag; Save via `StubLedgerEngine` |
| `HistoryDetailView` | Custom badge reads `customSplit` |

## Mapping to Spec / PRD

| Requirement | Implementation |
|-------------|----------------|
| Open vs saved | Unlocked Assign now vs Saved and locked + lock (PIP-85 Pi* chrome) |
| One-time % change then Save | `applyCreditLock` / `StubLedgerEngine.saveAndLockCredit`; BR-5 second lock rejected |
| Suggested standing split | `suggestedStandingPercentages` (= standing / equal / 100% single) |
| `customSplit` flag | Set on Save when % ≠ suggested; badge via `showsCustomSplitBadge` |
| Create goal while open | `addGoalToOpenCredit` — saved ₹0; this-credit row at 0%; totals unchanged until Save |
| Goal totals on Save only | Open path never mutates `savedAmount`; lock adds allocation amounts |
| Stub engine (PIP-98 pending) | `StubLedgerEngine` delegates to `CreditEntryService` (+ pending edits from PIP-102) |
