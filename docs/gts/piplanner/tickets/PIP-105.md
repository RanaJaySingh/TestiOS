# PIP-105 Goal detail + Standing split

Ticket: https://linear.app/telco-paytm/issue/PIP-105/goal-detail-standing-split

## Delivered

Goal detail → Goal form (held edit until next credit via engine pending path). New goal from Goals tab persists through `LedgerEngineCore.createGoal`; Standing split presents when a second (or later) goal is added; one goal skips at 100%.

| Type / file | Role |
|-------------|------|
| `Services/GoalDetailStandingService.swift` | Linux-testable façade: `commitHeldEdit` → `updateGoalPending`; `addGoal` → `createGoal` + standing present flag |
| `Views/Goals/GoalDetailView.swift` | Edit navigates to `GoalFormView` (heldEdit); toast / held banner unchanged |
| `ViewModels/GoalDetailViewModel.swift` | `saveHeldEdit` via engine pending path |
| `Views/Setup/GoalFormView.swift` | `GoalFormMode.create` / `.heldEdit`; create/held save callbacks |
| `Views/Goals/GoalsTabView.swift` | New goal → engine create; Standing sheet after 2nd goal (sequenced after form dismiss) |
| `ViewModels/GoalsViewModel.swift` | `createGoalFromForm` / `presentStandingSplit` |
| `ViewModels/GoalEditViewModel.swift` | Save also uses `GoalDetailStandingService` / `updateGoalPending` (keep-both with form path) |
| `PiPlannerTests/GoalDetailStandingServiceTests.swift` | 1-goal skip, 2nd-goal present, held edit leaves History intact |
